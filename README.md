# Jogo Letras EAD

Educational quiz game developed for the Distance Learning Literature Program (Letras EAD) at [Unipampa](https://unipampa.edu.br/).

## Overview

Jogo Letras EAD is a web-based educational game inspired by the Brazilian TV show *Show do Milhão*, designed to support learning activities and student engagement in the Letras EAD program.

Players answer multiple-choice questions while progressing through increasingly challenging stages, combining educational content with game-based learning mechanics.

## Features

- Multiple-choice quiz system
- Educational content management
- Score and progression system
- Web-based interface
- Learning-oriented gameplay

## Technologies

- PHP
- JavaScript
- HTML
- CSS
- Web Development

## Project Context

Developed for the Distance Learning Literature Program (Letras EAD) at the Federal University of Pampa (Unipampa).

## Historical Relevance

One of my earliest complete software projects, involving web development, game mechanics, educational technology, and user interaction design.
